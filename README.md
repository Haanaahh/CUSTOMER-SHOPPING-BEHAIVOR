# 🛍️ Customer Shopping Behavior Analysis

An end-to-end data analytics project analyzing customer shopping behavior and purchasing patterns.

### 📌 Project Overview

This project follows a complete data analytics workflow:

**Python → PostgreSQL/SQL → Power BI**

### 🐍 Python — Data Analysis

* Data cleaning and preprocessing
* Exploratory data analysis
* Customer and purchasing behavior analysis
* Identified key patterns and trends

### 🗄️ SQL — PostgreSQL

* Loaded the processed dataset into PostgreSQL
* Used SQL queries to analyze customer and sales data
* Performed revenue, customer, and purchasing analysis

### 📊 Power BI — Dashboard

* Created an interactive dashboard
* Visualized key KPIs and customer insights
* Presented purchasing patterns and business trends

### 🛠️ Tools Used

`Python` `Pandas` `SQL` `PostgreSQL` `pgAdmin 4` `Power BI`

### 🎯 Objective

To transform raw customer shopping data into meaningful insights using **Python, SQL, and Power BI**, demonstrating an end-to-end data analytics workflow.
